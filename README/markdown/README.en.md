# Evolution of a specific CA type, displayed via CLI.

[![en](/README/markdown/assets/language-badges/en.svg)](/README/markdown/README.en.md)

The main system file is `./main.py`. Running it from the command line generates and displays evolution variations of a 1-dimensional closed CA according to Wolfram's classification.

You can change the system parameters in `./parameters/parameters.py`.
