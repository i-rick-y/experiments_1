Эволюция КЛА определенного типа с отображением через CLI.

  Главный файл системы - **./main.py**. Запустив его из командной строки, сгенерирутся и выведутся вариации эфолюции 1-мерного замкнутого КЛА согласно классификации Вольфрама.
  Изменить параметры системы можно в **./parameters/parameters.py**.
